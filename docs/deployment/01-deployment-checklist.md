# Deployment Checklist

## Before deployment
- [ ] Production environment created
- [ ] Production DB created
- [ ] Migrations applied
- [ ] Storage configured
- [ ] Domain/DNS configured
- [ ] HTTPS verified
- [ ] Environment variables configured
- [ ] Admin account provisioned securely
- [ ] Analytics configured
- [ ] Search Console configured
- [ ] Optional WhatsApp integration configured

## Smoke tests
- [ ] Public home
- [ ] Search
- [ ] Model details
- [ ] Booking request
- [ ] Status URL
- [ ] Owner login
- [ ] Confirm booking
- [ ] Reject booking
- [ ] Modify schedule
- [ ] Reassign vehicle
- [ ] Offline booking
- [ ] Vehicle block
- [ ] Business closure
- [ ] Calendar
- [ ] CSV export
- [ ] WhatsApp click-to-chat

## Handover
- [ ] Client owns domain account
- [ ] Client owns hosting account
- [ ] Client owns storage/database account where appropriate
- [ ] Client receives admin credentials
- [ ] Client receives analytics/Search Console access
- [ ] Backup/recovery notes delivered
- [ ] Support terms explained
