# Screen Design Specification

## Homepage
Order:
1. Header/navigation
2. Hero statement
3. Prominent booking search
4. Trust/proof strip
5. Featured fleet
6. Why choose us
7. How it works
8. Reviews
9. Location/contact
10. Footer

The public homepage must feel like the client's business website, not an admin application.

## Search results
Header showing selected search period.
Result cards include image, model, specs, price/day, available count and CTA.
Default list excludes models with zero eligible vehicles.

## Model details
Large gallery, model/spec/pricing block, selected rental interval, availability count, policy summary, booking CTA and contact actions.

## Booking form
Use a clear summary panel, customer fields, policy acknowledgement and prominent `Submit Booking Request` action.

## Request success
Show reference, PENDING state, requested period, status link and expectation that owner confirmation is not instantaneous.

## Private status page
Show only permitted booking information and a clear state timeline.
Example:
`Request received → Awaiting confirmation → Confirmed → Ongoing → Completed`

## Owner dashboard
Action-first layout:
- Action Required
- Today
- Fleet summary
- Upcoming schedule

## Owner calendar
Week-first; day detail for crowded days; click event opens detail/actions.

## Owner fleet
Model-level list -> physical vehicles.
Do not force owners to duplicate generic model images for every vehicle.
